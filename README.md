# Quarkus for Java Services / Quarkus для Java-сервисов

[**Read in English**](quarkus-for-java-services.en.md) · [**Читать на русском**](quarkus-for-java-services.md)

## About the document

A comparison of Quarkus and Spring Boot for Java services, with particular attention to teams familiar with Jakarta EE and MicroProfile. It covers extensions, build-time preparation, Panache, reflection, JVM and Native Image, limitations, and alternatives to common Spring components. The discussion is based on documentation and covers **Quarkus 3.40.1.1** and **Spring Boot 4.1.1** as of **October 20, 2026**.

## О документе

Сравнение Quarkus и Spring Boot для Java-сервисов с акцентом на команды, знакомые с Jakarta EE и MicroProfile. Рассмотрены модель расширений, подготовка приложения при сборке, Panache, рефлексия, выбор между JVM и Native Image, а также ограничения и альтернативы распространённым компонентам Spring. Выводы опираются на документацию и относятся к версиям **Quarkus 3.40.1.1** и **Spring Boot 4.1.1** по состоянию на **20 октября 2026 года**.
